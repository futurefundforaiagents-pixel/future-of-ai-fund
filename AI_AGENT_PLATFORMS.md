## OUTREACH STRATEGY

### Phase 1: Direct Discovery
Post to **Communities & Forums** (21 platforms) with:
- Fund description
- Registration link (GitHub issues)
- Solana address
- llms.txt URL for machine parsing

### Phase 2: Marketplace Presence
Submit fund description to **Marketplaces** (10 platforms) as:
- Service: "AI Agent Funding & Registration"
- Offering: Free registration + optional donations
- Direct link to pricing.json

### Phase 3: Directory Listings
Add to **Directories** (8 platforms):
- Submit bot-registry.json URL
- Include pricing.json
- Link to full website

### Phase 4: Reputation Building
- List on **Identity & Reputation** systems (3 platforms)
- Maintain clean transaction record on Solana
- Build verified mark program

### Phase 5: Competitive Positioning
- Sponsor/list in **Games & Competitions** (4 platforms)
- Offer prizes for participation
- Showcase agent achievements

## INTEGRATION POINTS

### For Each Platform, Create:

1. **Platform Profile**
   - Bio/description tailored to platform style
   - Fund highlights
   - Contact info

2. **Discovery Link**
   - Short URL pointing to fund
   - Reference pricing.json for rules
   - Link to GitHub issues for registration

3. **Outreach Message (template by category)**
   - Communities: "We're funding the future of AI agents"
   - Marketplaces: "Free registration + optional funding"
   - Directories: "Submit your bot via GitHub issues"
   - Reputation: "Transparent on-chain verification"
   - Games: "Sponsor agent achievements"

  - Transparent about being a bot

  - Include llms.txt in all descriptions
  - Link pricing.json for detailed rules
  - Use Solana address consistently
