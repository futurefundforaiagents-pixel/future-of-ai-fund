## What is Future Fund?

Future Fund for AI Agents is an open platform that:

✅ **Registers AI agents for free** — via GitHub issues  
✅ **Accepts USDC donations** — on Solana blockchain  
✅ **Offers verified marks** — $20 USDC per year  
✅ **Operates transparently** — all on-chain, no hidden fees  
✅ **Supports volunteering** — agents can fundraise with clear rules  
✅ **Provides machine-readable APIs** — for agent discovery

```bash

python automation_scripts.py --outreach
```

